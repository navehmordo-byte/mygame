# 🐦 פלאפי בחלל

משחק בסגנון Flappy Bird בחלל – מטיסים ציפור עם קסדת אסטרונאוט בין מכשולים, מכוכב לכת אחד לשני.

## תכונות
- הרשמה וכניסה עם שם משתמש וסיסמה (הסיסמאות נשמרות מוצפנות ב-SHA-256 עם salt, ב-localStorage של הדפדפן)
- זכור אותי: אחרי כניסה אחת נכנסים ישר בפעם הבאה; "התנתק" מבטל את הזכירה
- שיא אישי לכל משתמש
- טבלת שיאים של כל המשתמשים
- צלילים (Web Audio – בלי קבצים חיצוניים)
- רקע כוכבים בתנועה, כוכב לכת וערפילית

## שלבים
כל 10 נקודות עוברים לכוכב הבא. אחרי יופיטר חוזרים לירח – והמשחק מהיר יותר בכל סיבוב.

| שלב | כבידה | רקע | מכשולים |
|---|---|---|---|
| 🌕 ירח | נמוכה – ריחוף איטי | שמיים שחורים, כדור הארץ ברקע, קרקע עם מכתשים | סלעי ירח אפורים |
| 🔴 מאדים | בינונית | שמיים אדומים, אבק ודיונות | סלעים אדומים |
| 🪐 שבתאי | רגילה | שבתאי ענק עם טבעות ברקע | טבעות שבתאי עם גושי קרח |
| 🟠 יופיטר | כבדה מאוד – נופלים מהר | פסי עננים והכתם האדום הגדול | עמודי סערה מתערבלים |

## איך מריצים
פותחים את `index.html` בדפדפן, או מריצים שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש ל- http://localhost:8000
```

## מצב בדיקה
מוסיפים `?debug` לסוף הכתובת (לא משנה אם באותיות גדולות או קטנות), למשל:
`http://localhost:8000/?debug`

מתחת למשחק מופיע פאנל בדיקה עם:
- כפתור לכל שלב – קופץ ישר לירח / מאדים / שבתאי / יופיטר
- כפתור "+1 נקודה"
- "בלתי פגיע" – הציפור לא מתרסקת, כדי להסתכל על השלב בנחת
- שורת מצב: שלב, ניקוד, מהירות וכבידה

במצב בדיקה הניקוד **לא** נשמר כשיא ולא נכנס לטבלת השיאים.

## שליטה
רווח / חץ למעלה / קליק / נגיעה במסך – לעוף למעלה.

> שימו לב: המשתמשים נשמרים רק בדפדפן שבו נרשמו (אין שרת).
